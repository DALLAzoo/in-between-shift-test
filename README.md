# In-between Shift 고객 사이트 4차 독립 시험본

기존 4차 시험본의 HTML/CSS/JS를 변경하지 않고, 빠져 있던 PWA 의존 파일 4개를 추가했습니다.

추가: manifest.webmanifest, sw.js, in_between_shift_icon_192.png, in_between_shift_icon_512.png

주의: 이 PWA 파일들은 현재 작업 환경에서 확보된 동일 이름의 파일을 사용했습니다. GitHub 운영 저장소의 최신 파일과 완전히 같은지는 검증되지 않았습니다.

검증: HTML의 CSS/JS 파일 경로, manifest의 아이콘 경로와 파일 존재 여부 확인. 실제 모바일 브라우저/Firebase 기능 검증은 하지 않았습니다.

운영 GitHub에 바로 덮어쓰지 마세요. 별도 테스트 브랜치 또는 테스트 사이트에서 검증 후 적용해야 합니다.
